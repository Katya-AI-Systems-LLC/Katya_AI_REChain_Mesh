## 💡 Лучшие практики

### При использовании компонентов
```dart
// ✅ Хорошо
ModernCard(
  child: Text('Содержимое', style: EnhancedTheme.bodyM),
)

// ❌ Плохо
Container(
  decoration: BoxDecoration(color: Colors.blue),
  child: Text('Содержимое', style: TextStyle(fontSize: 14)),
)
```

### Для отступов
```dart
// ✅ Используйте SizedBox с фиксированными размерами
SizedBox(height: 16)

// ❌ Не используйте разные значения
SizedBox(height: 15.5)
```

### Для цветов
```dart
// ✅ Используйте токены из EnhancedTheme
color: EnhancedTheme.primary

// ❌ Не используйте хардкод
color: Color(0xFF6C63FF)
```

## 🐛 Известные проблемы

| Проблема | Решение |
|----------|---------|
| Shimmer не анимируется | Убедитесь что Widget в State с vsync |
| Карточка не реагирует на tap | Используйте `onTap` вместо GestureDetector |
| Неправильные тени | Проверьте `EnhancedTheme.shadowColor` |
