# 📱 Обновление стартового экрана приложения

## ✨ Что было изменено?

При запуске приложения теперь открывается **страница профиля пользователя** (`ProfilePage`) вместо домашней страницы (`HomePage`).

### Новые возможности:

✅ **Персональный профиль** с отображением:
- Имя пользователя и статус (Online)
- Аватар с градиентом
- Биография
- Интересы (теги)

✅ **Статистика профиля:**
- Количество подписчиков
- Количество подписок
- Количество постов

✅ **Полная навигация проекта** со ссылками на:
- 🏠 Главная (HomePage)
- 💬 Сообщения (MessengerPage)
- 📱 Устройства (DevicesPage)
- 🗳️ Голосования (VotingScreen)
- 🤖 Katya AI (AIPage)
- ⚙️ Настройки (SettingsPage)

## 🎨 Дизайн

- **Glass morfизм** - полупрозрачные карточки
- **Фон с частицами** - динамический космический фон
- **Темная тема** - комфортная для глаз
- **Плавные переходы** - красивая анимация при клике на пункты меню
- **Адаптивный дизайн** - работает на всех размерах экранов

## 📂 Затронутые файлы

### Новые файлы:
- `lib/src/ui/profile_page.dart` - Новая страница профиля с навигацией

### Модифицированные файлы:
- `lib/src/ui/splash.dart` - Изменен переход на ProfilePage вместо HomePage

## 🚀 Как это работает?

1. Приложение запускается через `main.dart`
2. Если требуются разрешения, показывается `PermissionsScreen`
3. После получения разрешений или при запуске с существующими разрешениями загружается `App`
4. В `splash.dart` после 3-секундной заставки пользователь переходит на **новую `ProfilePage`**
5. Из `ProfilePage` пользователь может перейти в любой раздел проекта

## 🔄 Как вернуться к старому поведению?

Если хотите вернуться к старому запуску с `HomePage`, отредактируйте `lib/src/ui/splash.dart`:

```dart
// Текущее (новое):
Navigator.of(context).pushReplacement(
  MaterialPageRoute(builder: (context) => const ProfilePage()),
);

// Старое:
Navigator.of(context).pushReplacement(
  MaterialPageRoute(builder: (context) => const HomePage()),
);
```
