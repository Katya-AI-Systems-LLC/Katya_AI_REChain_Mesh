## 🎯 Как это работает?

### Цепочка запуска:
```
main.dart (runApp)
    ↓
PermissionsScreen (если нужны разрешения)
    ↓
App (из app.dart)
    ↓ (по маршруту из AppRouter)
SplashPage (заставка 3 сек)
    ↓
ProfilePage ← НОВОЕ! (вместо HomePage)
    ↓ (по клику на пункт меню)
Любая страница проекта
```

### Пользовательский поток:

1. **Запуск** → Видит SplashScreen
2. **Ожидание 3 сек** → Заставка с анимацией
3. **Переход** → Открывается ProfilePage
4. **Выбор** → Пользователь видит свой профиль с ссылками:
   - Может перейти на главную (HomePage)
   - Может открыть сообщения
   - Может управлять устройствами
   - Может участвовать в голосованиях
   - Может общаться с AI
   - Может открыть настройки
