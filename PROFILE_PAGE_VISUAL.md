## Цветовая схема

### Основные цвета:
- **Фон**: `EnhancedTheme.darkBg` (очень темный, почти черный)
- **Градиент**: `EnhancedTheme.spaceGradient` (космический синий-фиолетовый)
- **Текст**: Белый (`Colors.white`)
- **Акцент**: `EnhancedTheme.accent` (яркий голубой)
- **Статус Online**: `Colors.green` (ярко-зеленый)

### Карточки:
- Полупрозрачные (glass morfизм)
- С градиентом бордюра
- Мягкие тени

## Интерактивные элементы

### Пункты меню при наведении:
```
❌ До наведения:           ✅ При наведении:
┌─────────────────┐       ┌─────────────────┐
│ 📱 Устройства   │  →   │ 📱 Устройства   │
│ Описание        │       │ Описание        │
│              → │       │              → │ (светится)
└─────────────────┘       └─────────────────┘
  (серый значок)         (голубой значок)
```

### При клике:
- Плавная анимация перехода
- Открывается выбранная страница
- MaterialPageRoute с 300ms анимацией

## Анимации

### Заставка (SplashScreen):
1. Логотип появляется с `Curves.elasticOut` (2 сек)
2. Текст фейдится `Curves.easeInOut` (1.5 сек)
3. Частицы анимируются `Curves.linear` (бесконечно)
4. После 3 сек → переход на ProfilePage

### ProfilePage:
- Частицы в фоне движутся плавно
- При наведении на пункты меню → подсветка
- При клике → переход с MaterialPageRoute

## Размеры элементов

- **Экран**: Полный размер устройства
- **Аватар**: 100x100px
- **Карточки профиля**: Ширина ~320px, высота динамическая
- **Пункты меню**: Ширина экрана - 40px (margin)
- **Иконки**: 24-50px в зависимости от контекста
- **Текст**: 
  - Заголовок: 24-28pt
  - Подзаголовок: 16-18pt
  - Основной: 14pt
  - Маленький: 12pt

## Отзывчивость (Responsiveness)

- ✅ Работает на телефонах (360x640px+)
- ✅ Работает на планшетах (768x1024px+)
- ✅ Работает на больших экранах
- ✅ Использует `SingleChildScrollView` для скроллинга
- ✅ Flexbox макеты автоматически подстраиваются
